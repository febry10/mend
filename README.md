mend is one patch tool for every AI edit format: it reads a unified diff, SEARCH/REPLACE blocks, a V4A patch or JSON text-editor calls, finds the lines each edit names even when line numbers are wrong or whitespace has drifted, and writes every change or none, printing what it changed or why it failed. Node 22, standard library only.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
